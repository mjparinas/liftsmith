# Tempo coach

- **A lab** (Melvin, 2026-11-11, Labs idea round 2, #5: "tempo coach, sound + haptic count per rep phase"). Flag `labTempo`, off by default, Settings › Labs › Tempo coach; Pro like every lab.
- **Which sets:** tempo and paused lifts only, the ones whose cues give seconds (`TEMPOS` in `src/lib/tempo.ts`: the six `tempo-*` lifts and the ten `pause-*`/`paused-*` ones). Each lift's phases and seconds are read from its own how-to cues ("Take three slow seconds on the way down"), so the coach counts what the demo says; a phase the cues don't time gets one second. A phase list, in the lift's own order, so a paused deadlift (pull, hold below the knee, finish, lower) and pulling lifts (words Pull and Return) work too. `tempo.test.ts` fails if a `tempo-`, `pause-` or `paused-` exercise is added without a tempo.
- **The demo plays the same tempo** (Melvin, 2026-11-12: "Swapping a workout doesn't seem to change the 3D animation to match"). A paused or tempo lift used to share its plain cousin's motion exactly, so swapping a back squat for a pause squat left the figure looking the same. `motionFor` now replaces a lift's phases with its `TEMPOS` entry (`src/lib/demo/tempoMotion.ts`): the slow lowering, the pause held still at the bottom (or partway up, for the paused deadlift) and the phase line saying so ("Pause · 2s"), in the same seconds the coach counts. The demo itself already redraws on a swap (`LiftDemoSwap.test.tsx` keeps it so); the remaining look-alike swaps are equipment cousins that still share one motion (smith row and barbell row, the pullover family), left for a later motion pass. Shared web code, so Android, iOS and the web get it together.
- **On the workout screen:** while the lab is on and the set is a tempo lift, a **Count tempo** button sits above Log set (beside Undo and Say a set; `workout/TempoCoach.tsx`), with the tempo in words under it ("3 s down · 1 s up"). Tap it as you take the weight: "Get set" 3, 2, 1, then one beat a second for every planned rep, and the line says the phase, seconds left and the rep ("Lower 3 · rep 2 of 8"). It stops by itself after the planned reps (a success buzz), on Stop, when Log set starts rest, or when a sheet opens or the app leaves the screen. It never logs: Log set is still one tap, and the button is an extra, not a step (the "never add a tap during a set" rule covers required taps).
- **Sounds and haptics** (`sound.tempo` in `juice.ts`, same mallet voice and A major pentatonic as every other sound): a new phase has its own shape so it can be told apart without looking (lower: a falling pair, hold: one middle note, lift: a rising pair), each further second a quiet tick at that phase's pitch, the lead-in the rest countdown's tick. Haptics: `select` for each second, `tick` for a new lower or hold, `tap` (stronger) for the lift. Both follow the Sounds and Vibration switches; the words on screen are always there.
- **Timing:** each beat is scheduled from the start time (`timeline()` gives every beat's offset), so a late timer doesn't drift the rest of the set. Timers run only while counting, so nothing runs in the background ([Battery](battery.md)).
- **Platforms:** pure web code (Web Audio and `@capacitor/haptics`), so Android, iOS and the web app get it together. Browsers without vibration (Safari) get the sound and words only, as with every haptic.
- **Not yet:** syncing to camera-counted reps, a lifter's own tempo for any lift, and the lock-screen notification or watch counting the tempo; worth doing if the lab gets used.
