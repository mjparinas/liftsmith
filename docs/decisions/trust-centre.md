# Trust centre (Melvin, 2026-11-10: "add a trust centre similar to Gradelings")

Part of the decision record. [AGENTS.md](../../AGENTS.md) has the rules that apply to every change and the list of topics. Record decisions about this topic here, in the same change as the code.

- **`/trust/`** (`src/app/trust/page.tsx`, `TRUST_GROUPS` in `src/components/site/TrustCentre.tsx`), laid out like Gradelings' `/trust/`: groups of controls (Privacy, Health data, Accounts, Payments, Infrastructure, Email and AI, Operations), one short line each with a shield, a "Last checked" date (`TRUST_UPDATED`), links to `/privacy/` and `/delete-account/`, and a "Report a security problem" section. High level, not verbose: a note stays under 90 characters (`trust.test.tsx`).
- **Claim only what ships.** Every line was checked against the code on 2026-11-10 (offline-first event log, optional account, usage stats off by default in the EU/EEA/UK/Switzerland, cookieless site counting with Global Privacy Control, Health Connect Limited Use, on-device rep counting, backup exclusion, hashed session tokens, email code try limits, RevenueCat and the stores for payment, the webhook's shared secret, security headers and the script policy, self-hosted code, database rate limits, Resend's SPF and DKIM records, AI drafts with human replies, admin two-step sign-in and audit log, the admin panel showing only counts of synced data, CI tests and `npm audit`, the 2026-11-09 security audit, and UptimeRobot watching `/api/health/`, which the admin System tab reads with `UPTIMEROBOT_API_KEY`). Something still being built can be listed with `status: "progress"`; anything we don't do is left out rather than softened. Health data is described as "only what you allow", not "read-only", because the app writes a finished workout's calories and heart rate back.
- **Left out on purpose** (Gradelings has them, Liftsmith doesn't yet): a public status page, DMARC (`_dmarc.getliftsmith.com` has no record as of 2026-11-10), and where the data is stored (the Turso region isn't recorded anywhere). Add each line when it's true.
- **`/.well-known/security.txt`** (RFC 9116): contact hello@getliftsmith.com, canonical on the www host, policy pointing at `/trust/`. It expires a year out; `trust.test.tsx` fails once it has expired, which is the reminder to renew it and re-check the page.
- Linked from the site footer next to Privacy, in the sitemap (`siteRoutes`), and scanned by the axe run. English only, like the rest of the website, and it imports no language catalogue.
- When a control, provider or setting changes, update the line here and on `/privacy/` in the same change, and move `TRUST_UPDATED`.
