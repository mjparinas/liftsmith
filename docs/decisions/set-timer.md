# Set timer for holds, carries and hangs

Part of the decision record. [AGENTS.md](../../AGENTS.md) has the rules that apply to every change and the list of topics. Record decisions about this topic here, in the same change as the code.

- **Why** (Melvin, 2026-11-12: "For some exercises that require a length of time, can you add a timer functionality"). Holds, carries, hangs and timed drills were already planned and logged in seconds (`TIMED` in `progression.ts`: plank, side plank, dead hang, wall sit, farmer's carry and about 180 more, cardio included), but the lifter had to time them on another clock and then dial the seconds in.
- **What it does** (`src/lib/setTimer.ts`, pure and tested; `workout/SetTimer.tsx`). On any `TIMED` exercise a **Start timer · 0:40** button sits above Log set (free, not a lab). One tap starts a **5-second lead-in** ("Get set") to get into position, then the set **counts down** from the seconds dialled in, in a big clock in the button's place, with a bar and "Log set saves 0:12". When it runs out **the set logs itself** at the moment it ended, so the rest timer starts as after any set: a plank is one tap, not two, and Undo takes it back. **Log set while it runs saves the seconds actually held** (during the lead-in it logs the set as planned). **Cancel** stops it without logging.
- **Each side** (`perSide`, e.g. suitcase hold, bottoms-up kettlebell hold, split squat hold): "Start timer · 0:20 a side" counts the first side, gives 5 s to switch ("Switch sides"), then counts the second. Stopping on the second side logs the first side's full time and the second side's own (`repsL`/`repsR`, as when the sides differ).
- **Cardio counts up** ("Start the clock"), because its target is only last time's, to repeat or beat: it chimes once on passing the target, keeps going, and Log set saves the time. It never logs itself.
- **Sound, touch and voice** follow the Sounds and Vibration switches: a tick on the last three seconds of the lead-in, the switch and the hold, the rest-over chime and a thud on go, a goal chime when cardio passes its target. The voice coach (when on) says "Ten seconds" on holds of 20 s or more and "Switch sides". Text is `timer.*` in all six languages.
- **The clock is wall time**, kept outside the screen (`startTimer`/`takeTimer` in `SetTimer.tsx`), so going to Today and back mid-hold keeps it, and a hold that ran out while the app was in the background logs at the moment it ended, without late beeps. It belongs to one set; once that set is logged it's gone.
- **Platforms:** pure web code, so Android, iOS and the web app get it together. The screen stays on during a workout by default, which covers a phone on the floor beside a plank.
- **Not built yet:** the hold's countdown on the lock-screen notification, Live Activity and watches (they show the set and the rest timer only), and a timer on warm-ups (timed exercises have none).
